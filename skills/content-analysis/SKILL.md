# 深度内容分析框架

## Overview

本技能提供了一个系统化的内容分析框架，用于对文章、论文、报告、书籍章节等文本进行深度解读。框架从五个维度展开：**核心内容**、**背景语境**、**批判性审视**、**价值提取**和**写作技巧分析**，帮助读者全面理解作者的论点、论证逻辑和深层假设。

## When to Use This Skill

使用此 skill 当用户需要：
- 深度分析一篇文章的核心论点和论证结构
- 理解作者的背景、立场和潜在假设
- 对观点进行批判性审视，发现漏洞和边界条件
- 从内容中提取可复用的思考框架和方法论
- 学习优秀文章的写作技巧

## 分析框架

### 一、核心内容（搞清楚"是什么"）

1. **文章的核心论点是什么？用一句话概括**
   - 提炼文章最核心的主张
   - 识别文章的"唯一论点"（如果有的话）

2. **作者用了哪些关键概念？这些概念是怎么定义的？**
   - 列出文章中的核心术语
   - 分析作者对这些概念的定义是否清晰、是否有新意
   - 识别概念之间的关系

3. **文章的结构是什么？论证是怎么展开的？**
   - 分析文章的逻辑结构（总分总、递进、对比等）
   - 识别论证的主线和支线
   - 看论证是如何层层推进的

4. **有哪些具体案例或证据支撑观点？**
   - 列举作者使用的案例、数据、引用
   - 分析这些证据的说服力如何
   - 识别证据的类型（经验、数据、权威引用、逻辑推理等）

### 二、背景语境（理解"为什么"）

1. **作者是谁？他的背景、身份、立场是什么？**
   - 作者的职业、经历、代表利益群体
   - 作者此前关于此话题的公开观点
   - 作者可能的立场倾向

2. **这篇文章是在什么背景下写的？在回应什么现象或争论？**
   - 写作的时间节点和社会背景
   - 文章可能针对的某个具体事件、观点或争论
   - 写作的外部动机

3. **作者想解决什么问题？想影响谁？**
   - 文章试图回答的核心问题
   - 作者的目标读者是谁
   - 作者希望读者看完后有什么行动或认知变化

4. **作者的底层假设是什么？有哪些没说出来的前提？**
   - 文章成立的隐含前提
   - 作者认为"不言自明"的那些事实
   - 容易被忽视但至关重要的假设

### 三、批判性审视

1. **有人会怎么反驳这个观点？主要的反对意见可能是什么？**
   - 从反对角度思考，列出可能的反驳点
   - 考虑不同立场群体的质疑
   - 识别论证中的薄弱环节

2. **作者的论证有没有漏洞、跳跃或偏颇之处？**
   - 逻辑谬误（稻草人谬误、滑坡谬误、以偏概全等）
   - 证据不足或证据选择偏见
   - 论证链条中的缺失环节

3. **这个观点在什么情况下成立？什么情况下不成立？边界在哪里？**
   - 限定条件和适用范围
   - 反例和边界情况
   - 观点的适用前提

4. **作者有没有刻意回避或淡化什么问题？**
   - 文章未涉及的敏感话题
   - 对不利证据的忽略
   - 可能存在的认知盲区

### 四、价值提取

1. **作者提出了什么可复用的思考框架或方法论？**
   - 抽象出普适性的思考模型
   - 识别可以迁移到其他场景的方法
   - 提炼可操作的行动指南

2. **对于[目标读者角色1]，能从中学到什么？**
   - 针对不同角色分析学习价值
   - 识别可立即应用的洞见

3. **对于[目标读者角色2]，能从中学到什么？**
   - 多角度分析内容的价值

4. **这篇文章可能改变读者的什么认知？**
   - 文章可能带来的认知转变
   - 读者看待问题的新视角

### 五、写作技巧分析（可选）

1. **文章的标题、开头、结尾是怎么设计的？**
   - 标题的吸引力和信息量
   - 开头的切入方式和悬念设置
   - 结尾的收束方式和行动呼吁

2. **作者用了什么技巧让文章有说服力？**
   - 修辞技巧方式
   - 叙事技巧和情感共鸣
   - 结构和节奏和表达设计

3. **这篇文章的写法有什么值得学习的地方？**
   - 可借鉴的写作方法
   - 可以改进的地方

## 使用示例

### 示例 1：分析一篇观点文章

**用户**: "分析这篇文章的核心论点：https://example.com/article"

Agent 将会：
1. 抓取文章内容
2. 按照框架逐一分析五个维度
3. 输出结构化的分析报告

### 示例 2：深度解读一篇论文

**用户**: "帮我深度解读这篇关于 AI 安全的论文"

Agent 将会：
1. 识别论文的核心贡献
2. 分析论文的论证逻辑
3. 批判性审视方法论的有效性
4. 提取可借鉴的研究框架

### 示例 3：评论一个观点

**用户**: "评论这个观点：'远程工作是企业效率提升的最佳方案'"

Agent 将会：
1. 明确核心论点的边界
2. 分析隐含假设
3. 提供支持和反对的论据
4. 给出平衡的评估

## 输出格式

分析报告采用结构化格式，每个维度清晰呈现，既有原文引用也有分析洞见。避免泛泛而谈，要求给出具体、可操作的洞察。

```markdown
# 内容深度分析报告

## 一、核心内容

### 1.1 核心论点
一句话概括...

### 1.2 关键概念
- 概念 A：定义...
- 概念 B：定义...

### 1.3 文章结构
...

### 1.4 证据支撑
...

## 二、背景语境
...

## 三、批判性审视
...

## 四、价值提取
...

## 五、写作技巧
...
```

## 注意事项

1. **保持客观**：分析时保持中立立场，忠实还原作者观点
2. **具体深入**：避免泛泛而谈，每个观点都要有具体论据支撑
3. **多角度思考**：尝试从不同立场审视问题
4. **诚实承认局限**：如果信息不足无法分析某个维度，要明确说明
5. **结构清晰**：分析报告要有清晰的层次结构，便于阅读和理解
