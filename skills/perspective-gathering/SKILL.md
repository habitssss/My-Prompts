# 视角收集与利益相关者分析框架

## Overview

本技能提供了一个系统化的框架，用于识别讨论特定话题时最合适的参与者群体，并分析他们可能持有的观点和立场。通过多角度视角分析，帮助用户全面理解话题的不同面向，发现潜在的共识与分歧，为深度讨论或决策提供参考。

## When to Use This Skill

使用此 skill 当用户需要：
- 探讨某个话题时需要了解应该听取哪些人的意见
- 分析某个问题涉及哪些利益相关者
- 了解不同群体对某个话题的可能观点
- 为会议、讨论或决策收集多元视角
- 理解某个话题中的不同立场和论点

## 分析框架

### 一、利益相关者识别

1. **直接受影响群体**
   - 这个问题直接影响到谁？
   - 他们的核心诉求和痛点是什么？
   - 他们对问题的感知和理解程度如何？

2. **领域专家和专业权威**
   - 哪些学术或专业背景的人对此有深入研究？
   - 他们的专业观点通常是什么？
   - 不同专家之间是否存在观点分歧？

3. **决策者和执行者**
   - 谁有权决定或影响这个问题的发展方向？
   - 他们的考量因素和约束条件是什么？
   - 他们通常站在什么立场？

4. **相关产业链参与者**
   - 这个问题影响到哪些上下游产业？
   - 商业利益如何驱动他们的立场？
   - 行业协会有何态度？

5. **社会公众和舆论影响者**
   - 普通民众对此话题的关注点是什么？
   - 媒体和意见领袖如何塑造讨论？
   - 社会文化因素如何影响观点形成？

### 二、观点分析

1. **核心论点梳理**
   - 每个利益相关群体的核心主张是什么？
   - 支持其立场的主要论据有哪些？
   - 他们认为最关键的议题是什么？

2. **立场差异分析**
   - 不同群体之间存在哪些根本性分歧？
   - 这些分歧源于什么（利益、价值观、认知）？
   - 有无可能达成共识的领域？

3. **潜在共识识别**
   - 各群体是否存在共同关心的问题？
   - 有哪些可以折中或调和的点？
   - 共同利益的基础是什么？

4. **隐性假设和前提**
   - 各群体的论点基于什么隐含假设？
   - 他们认为"不言自明"的事实是什么？
   - 有哪些被忽视的边界条件？

### 三、讨论价值评估

1. **信息价值**
   - 哪个群体能提供最独特或稀缺的视角？
   - 哪些观点能带来最多的新信息？

2. **代表性评估**
   - 某个观点能代表多大比例的人群？
   - 是否存在被边缘化的重要声音？

3. **潜在盲点**
   - 哪些群体的视角可能被遗漏？
   - 当前讨论框架可能忽略什么问题？

### 四、综合建议

1. **核心参与者推荐**
   - 列出最应该邀请参与讨论的 3-5 个群体
   - 说明每个群体的独特价值

2. **讨论重点建议**
   - 基于多元视角，提出讨论时应该关注的核心问题
   - 建议如何平衡不同观点

3. **潜在挑战预警**
   - 可能出现的争议点和冲突
   - 需要特别注意的敏感议题

## 使用示例

### 示例 1：新技术采用话题

**用户**: "如果要探讨 AI 在医疗诊断中的应用，最合适的一群人是谁？他们会说些什么"

Agent 将会：
1. 识别利益相关者（医生、患者、医院管理者、AI 公司、监管机构、伦理学家等）
2. 分析各方观点（医生关注准确性和责任归属，患者关注隐私和安全，监管机构关注合规性等）
3. 评估讨论价值，给出核心参与者建议

### 示例 2：城市政策讨论

**用户**: "如果要讨论城市交通限行政策，谁会关心这个话题？他们分别会说什么"

Agent 将会：
1. 识别受影响群体（车主、公交用户、零售商家、环保人士、交通规划者等）
2. 分析各方立场和论点
3. 找出共识领域和潜在分歧点
4. 给出讨论建议

### 示例 3：行业标准制定

**用户**: "我们要讨论新能源汽车充电接口标准化的问题，应该听取谁的意见"

Agent 将会：
1. 列出关键利益相关者（汽车厂商、充电桩运营商、电力公司、消费者协会、政府部门等）
2. 分析各方的核心诉求和技术立场
3. 评估各方的影响力和代表性
4. 给出标准制定讨论的参与建议

## 注意事项

1. **保持客观**：呈现不同观点时保持中立，不偏袒任何立场
2. **全面覆盖**：尽量涵盖不同类型的利益相关者，避免遗漏重要群体
3. **具体分析**：避免泛泛而谈，每个群体的观点都要有具体论据
4. **承认局限**：明确说明分析的局限性，如信息不足可能导致推断
5. **平衡视角**：既关注分歧，也要寻找共识基础
