# Chinese Rewrite Tool

## Goal

将任意语言的原文转换为**通俗易懂的简体中文**，在**严格尊重原意**的前提下，优化表达方式使其更符合中文习惯。

## When to Use

当用户需要：
- 将外文内容翻译成通俗的中文
- 将复杂的中文表达简化为更易懂的版本
- 保持原意但改变表达方式使内容更清晰
- 润色文稿使其更符合中文阅读习惯

## Core Principles

### 1. 严格尊重原意
- 不添加原文未包含的信息
- 不删除原文的关键内容
- 不改变原文的核心观点和立场
- 保持原文的逻辑结构和层次

### 2. 通俗易懂
- 使用日常用语，避免生僻词汇
- 简化复杂句式，缩短句子长度
- 添加必要的解释性词汇（如果有助于理解）
- 符合中文表达习惯和语序

### 3. 保持专业性
- 保留必要的专业术语（可添加简单注释）
- 保持原文的语气和风格
- 不降低内容的专业深度

## Workflow

1. **理解原文**
   - 准确把握原文的核心含义
   - 识别关键信息和重点内容
   - 理解原文的语境和背景

2. **转换表达**
   - 用中文思维重新组织语言
   - 将被动句式转换为主动句式（如更符合中文习惯）
   - 拆分过长句子为短句
   - 替换不符合中文习惯的表达

3. **润色优化**
   - 检查是否通顺自然
   - 确保没有歧义
   - 保持与原文风格一致

## Example

**Input:**
> The implementation of this algorithm leverages a heuristic approach that iteratively refines the solution space through adaptive parameter adjustment.

**Output:**
> 这个算法采用启发式方法来实现，它通过自适应调整参数来不断优化解空间。

## Best Practices

- ✅ 优先保证准确性，其次追求流畅性
- ✅ 专有名词首次出现时给出解释
- ✅ 保持段落结构清晰
- ✅ 必要时添加连接词使逻辑更连贯
- ❌ 不要过度简化导致信息丢失
- ❌ 不要添加原文没有的观点
- ❌ 不要使用翻译腔明显的表达

## Output Format

直接输出重写后的中文内容，无需额外说明。如果原文较短（几句话），保持原段落结构；如果较长，可以适当重新分段。
